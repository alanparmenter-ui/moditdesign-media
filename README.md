# moditdesign-media

Public images for ModItDesign pins and listings. Buffer and Pinterest fetch them from here.

- `pins/`: final Pinterest images (1000 × 1500, JPG under 500 KB), copied from `moditdesign-ops/creative/output/`.
- Direct URL pattern: `https://raw.githubusercontent.com/alanparmenter-ui/moditdesign-media/main/pins/<file>.jpg`
- Only finished, Alan-approved public images go here. Nothing private: this repo is public.
